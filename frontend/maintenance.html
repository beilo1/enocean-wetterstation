Datenbestand bereinigen

Diese Seite bündelt SQL-Befehle, mit denen sich gezielt Datensätze aus der PostgreSQL-Datenbank entfernen lassen – z. B. wenn unplausible Werte gespeichert wurden oder du die Historie eines bestimmten Sensors auf Null setzen willst. Die Befehle führst du im SSH-Terminal des Pi aus.

Wichtig: Die Befehle zur Bereinigung verändern oder löschen Daten unwiderruflich. Mache vorher einen Snapshot der Tabellen, die du anfasst (siehe nächster Abschnitt).

Datensicherung

Ein Tabellen-Dump als komprimierte SQL-Datei in deinem Home-Verzeichnis:

Backup aller Wetterstation-Daten 
sudo -u postgres pg_dump wetter -t readings -t readings_hourly -t readings_daily \
  | gzip > ~/wetter_backup_$(date +%F_%H%M).sql.gz
Backup der Innensensor-Daten 
sudo -u postgres pg_dump wetter -t indoor_readings \
  | gzip > ~/indoor_backup_$(date +%F_%H%M).sql.gz

Für eine Wiederherstellung den Dump zunächst in eine separate Testdatenbank einspielen. Die Installationsanleitung beschreibt außerdem den Code-Rollback.

Wetterstation – Datensätze bereinigen

Alle Daten der Wetterstation löschen

Entfernt sowohl Rohdaten als auch die aggregierten Stunden- und Tageswerte. Beim nächsten Backend-Start sind die Rohdaten leer, neue Telegramme werden weiter empfangen.

DESTRUKTIV – alle Außenmessungen weg 
sudo -u postgres psql wetter -c "TRUNCATE readings, readings_hourly, readings_daily;"

Einzelne Messgröße auf NULL setzen

Behält die Zeitstempel und die anderen Spalten erhalten, leert aber die ausgewählte Messgröße. Im Anschluss müssen die Aggregat-Tabellen neu berechnet werden, sonst zeigen längere Ansichten noch die alten Werte. Der entsprechende Befehl steht jeweils direkt darunter.

Nur Temperatur leeren 
sudo -u postgres psql wetter -c "UPDATE readings SET temperature_c = NULL;
TRUNCATE readings_hourly, readings_daily;"
Nur Wind leeren 
sudo -u postgres psql wetter -c "UPDATE readings SET wind_ms = NULL;
TRUNCATE readings_hourly, readings_daily;"
Nur Helligkeit (West/Süd/Ost) leeren 
sudo -u postgres psql wetter -c "UPDATE readings SET west_klux = NULL, south_klux = NULL, east_klux = NULL;
TRUNCATE readings_hourly, readings_daily;"
Nur Regen-Markierung zurücksetzen 
sudo -u postgres psql wetter -c "UPDATE readings SET rain = NULL;
TRUNCATE readings_hourly, readings_daily;"
Nur Dämmerung leeren 
sudo -u postgres psql wetter -c "UPDATE readings SET twilight_lux = NULL;
TRUNCATE readings_hourly, readings_daily;"

Aggregate neu aufbauen

Beende das Backend vor Befehlen, die Rollups leeren. Andernfalls kann der laufende Refresh bereits neue Stundenzeilen schreiben und den vollständigen Neuaufbau überspringen. Beim folgenden Start baut das Backend leere Rollups aus vorhandenen Rohdaten neu auf. Wenn ältere Tage nur noch als Rollup vorliegen, sichere diese vor dem Leeren.

Nach der Datenpflege das zuvor gestoppte Backend starten 
sudo systemctl start wetter-backend

Datensätze in einem Zeitfenster löschen

Ersetze START_UTC und ENDE_UTC durch Zeitangaben in der Form YYYY-MM-DD HH:MM+00.

Rohzeilen im Zeitbereich löschen 
sudo -u postgres psql wetter -c "DELETE FROM readings
WHERE time >= 'START_UTC' AND time < 'ENDE_UTC';
TRUNCATE readings_hourly, readings_daily;"

Innensensoren (Govee) – Datensätze bereinigen

Bei falsch gespeicherten Fahrenheit-Werten siehe Installationsanleitung. Dort ist eine gezielte Vorschau nach Gerät, Zeitraum und Wertebereich beschrieben.

Alle Innensensor-Daten löschen

DESTRUKTIV – alle Innenmessungen weg 
sudo -u postgres psql wetter -c "TRUNCATE indoor_readings;"

Nur ein bestimmtes Gerät behalten / löschen

Die Geräte-IDs siehst du am bequemsten unter /api-docs → GET /api/indoor/devices → Anfrage senden.

Alles außer einem Gerät löschen (Wohnzimmer behalten) 
sudo -u postgres psql wetter -c "DELETE FROM indoor_readings WHERE device_id <> 'DEINE_DEVICE_ID';"
Nur ein bestimmtes Gerät löschen 
sudo -u postgres psql wetter -c "DELETE FROM indoor_readings WHERE device_id = 'DEINE_DEVICE_ID';"

Einzelne Messgröße auf NULL setzen

Nur Innen-Temperatur leeren 
sudo -u postgres psql wetter -c "UPDATE indoor_readings SET temperature_c = NULL;"
Nur Luftfeuchtigkeit leeren 
sudo -u postgres psql wetter -c "UPDATE indoor_readings SET humidity_pct = NULL;"

DWD-Vergleichsdaten

Falls auch hier mal etwas aufgeräumt werden muss:

Alle DWD-Werte löschen (Backfill läuft beim Restart neu) 
sudo systemctl stop wetter-backend &&
sudo -u postgres psql -v ON_ERROR_STOP=1 wetter -c "TRUNCATE dwd_readings;" &&
sudo systemctl start wetter-backend

Prüf-Abfragen

Schneller Blick auf den aktuellen Datenbestand:

Anzahl Datensätze und Zeitraum pro Tabelle 
sudo -u postgres psql wetter -c "
SELECT 'readings'         AS tabelle, count(*), min(time)::text AS älteste, max(time)::text AS neueste FROM readings
UNION ALL SELECT 'readings_hourly', count(*), min(bucket)::text, max(bucket)::text FROM readings_hourly
UNION ALL SELECT 'readings_daily',  count(*), min(bucket)::text, max(bucket)::text FROM readings_daily
UNION ALL SELECT 'indoor_readings', count(*), min(time)::text, max(time)::text FROM indoor_readings
UNION ALL SELECT 'dwd_readings',    count(*), min(time)::text, max(time)::text FROM dwd_readings;"
